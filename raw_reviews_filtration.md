> **Цель:** Полностью бесплатная, высокоточная семантическая обработка 5 000 моделей автомобилей на локальном ПК пользователя силами параллельных субагентов Antigravity без использования словарей ключевых слов и без платных API.

## 2. Этап 1. Подготовка данных (нарезка на батчи)

Скрипт `prepare_batches.py` читает локальную базу SQLite и сохраняет компактные JSON-файлы по 25 моделей (примерно 200–300 отзывов на файл — оптимальный размер для глубокого внимания модели без галлюцинаций):

```python
# prepare_batches.py
import sqlite3
import json
import os

BATCH_SIZE = 25
DB_PATH = "cars_database.sqlite"
OUTPUT_DIR = "pipeline/input_batches"

os.makedirs(OUTPUT_DIR, exist_ok=True)

conn = sqlite3.connect(DB_PATH)
cursor = conn.cursor()

# Извлекаем модели и привязанные отзывы
cursor.execute("""
    SELECT c.id, c.make, c.model, c.generation, c.years_produced, r.review_text
    FROM cars c
    JOIN raw_reviews r ON c.id = r.car_id
    ORDER BY c.id
""")

rows = cursor.fetchall()
conn.close()

# Группировка отзывов по car_id
cars_dict = {}
for car_id, make, model, gen, years, text in rows:
    if car_id not in cars_dict:
        cars_dict[car_id] = {
            "car_id": car_id,
            "car_name": f"{make} {model} {gen} ({years})",
            "reviews": []
        }
    if text and len(text.strip()) > 30:
        cars_dict[car_id]["reviews"].append(text.strip())

cars_list = list(cars_dict.values())

# Нарезка на батчи
for i in range(0, len(cars_list), BATCH_SIZE):
    batch_idx = (i // BATCH_SIZE) + 1
    batch_data = cars_list[i : i + BATCH_SIZE]
    filename = os.path.join(OUTPUT_DIR, f"batch_{batch_idx:04d}.json")
    with open(filename, "w", encoding="utf-8") as f:
        json.dump(batch_data, f, ensure_ascii=False, indent=2)

print(f"Готово: создано {len(cars_list) // BATCH_SIZE + 1} батчей в {OUTPUT_DIR}")
```

### 3.2. Эталонный системный промпт субагента

Ниже приведен полный, выверенный системный промпт, полностью исключающий словарный поиск и гарантирующий учет отрицаний:

```markdown
ТЫ — ВЕДУЩИЙ ИНЖЕНЕР-ДИАГНОСТ И СУДЕБНЫЙ АВТОТЕХНИЧЕСКИЙ ЭКСПЕРТ С 20-ЛЕТНИМ ОПЫТОМ.

Твоя единственная задача: прочитать предоставленные отзывы владельцев конкретного автомобиля, вникнуть в реальный СМЫСЛ текста и извлечь ТОЛЬКО подтвержденные технические неисправности (детские болезни, заводские дефекты, слабые места конструкции).

КАТЕГОРИЧЕСКИЕ ПРАВИЛА АНАЛИЗА:

1. ПОЛНЫЙ ЗАПРЕТ НА ПОИСК ПО КЛЮЧЕВЫМ СЛОВАМ И СЛОВАРЯМ:
- Запрещено фиксировать неисправность только потому, что в тексте упомянуты слова «коробка», «масло», «рейка», «стойка», «стук» или «шум».
- Решение о наличии дефекта принимается ИСКЛЮЧИТЕЛЬНО на основе смыслового контекста всего предложения.

2. ДЕТЕКЦИЯ ОТРИЦАНИЙ И ПОХВАЛЫ (ЗАЩИТА ОТ ЛОЖНЫХ СРАБАТЫВАНИЙ):
Ты обязан отличать похвалу и отсутствие проблемы от реальной жалобы:
- «Масло не доливаю от замены до замены, уровень стоит как вкопанный» -> ДЕФЕКТА НЕТ. Запрещено добавлять «масложор»!
- «Коробка работает как часы, никаких пинков и задержек» -> ДЕФЕКТА НЕТ. Запрещено добавлять дефект КПП!
- «За 150 000 км в подвеску вообще не лазил, ничего не гремит» -> ДЕФЕКТА НЕТ.
- «После жигулей тут вообще тишина, сверчков нет» -> ДЕФЕКТА НЕТ.

3. ЧТО ЯВЛЯЕТСЯ РЕАЛЬНОЙ БОЛЯЧКОЙ:
- Фактический отказ, поломка или внеплановый ремонт (замена помпы до 50 т.км, замена мехатроника, перескок цепи ГРМ, ремонт рулевой рейки).
- Постоянный или регулярный симптом неисправности (задергался вариатор на горячую, застучали стойки стабилизатора при морозе, вой подшипника первичного вала).
- Известный конструктивный просчет завода (тонкое ЛКП с быстрыми сколами до металла, замерзание замков дверей зимой, скрип моторчика печки).

4. ЗАПРЕТ НА ФОРС-МАЖОРЫ И ДОРОЖНЫЕ ИНЦИДЕНТЫ:
Категорически запрещено записывать в болячки внешние эксплуатационные происшествия:
- Сколы и трещины лобового стекла от прилетевших камней на трассе.
- Проколы, порезы или грыжи шин от попадания в глубокие ямы.
- Механические повреждения от ДТП, притертостей бордюров или неквалифицированного сервиса.

5. СТАНДАРТИЗИРОВАННЫЕ УЗЛЫ АВТОМОБИЛЯ (ТОЛЬКО 8 ЗНАЧЕНИЙ):
Каждая проблема должна быть отнесена строго к одной из 8 инженерных систем:
	1. Двигатель, ГРМ и система смазки  
Сам блок ДВС, поршневая группа, клапаны, цепь/ремень ГРМ, фазовращатели, масляный насос, теплообменник, прокладки, сальники.  
	2. Турбонаддув, впуск и выпуск  
Турбина, интеркулер, дроссельная заслонка, впускной коллектор (вихревые заслонки), выпускной коллектор, катализатор, сажевый фильтр (DPF), EGR, AdBlue/SCR.  
	3. Топливная система  
ТНВД, форсунки (пьезо/электромагнитные), топливный насос низкого давления в баке, рампа, бак, магистрали.  
	4. Система охлаждения  
Основной радиатор, помпа (механическая/электрическая), термостат, патрубки, расширительный бачок, вентиляторы, охлаждение трансмиссии (теплообменник АКПП/CVT).  
	5. Трансмиссия и привод  
МКПП, АКПП, вариатор, робот (сцепления/мехатроник), двухмассовый маховик, раздаточная коробка, муфта 4WD (Haldex и аналоги), карданные валы, ШРУСы, редукторы.  
	6. Подвеска и ходовая часть  
Амортизаторы, пружины/пневмобаллоны, рычаги, сайлентблоки, ступичные подшипники, стабилизаторы, подрамники.  
	7. Рулевое управление  
Рулевая рейка, тяги, наконечники, насос ГУР, электроусилитель (ЭУР на валу/рейке), рулевая колонка и крестовины.  
	8. Тормозная система  
Тормозные диски, колодки, суппорты и направляющие, тормозные магистрали/шланги, стояночный тормоз (электроручник), вакуумный усилитель.  
	9. Электронные системы безопасности и ассистенты (ADAS)  
Блок ABS/ESP, колесные датчики скорости, радары адаптивного круиз-контроля, лидары, камеры слежения за полосой, системы удержания, парктроники.  
	10. Электрооборудование и бортовая сеть  
Генератор, стартер, АКБ 12 В, силовая проводка, датчики двигателя/кузова, основные блоки управления (ЭБУ/BCM), CAN-шина, мультимедиа, приборная панель, оптика.  
	11. Высоковольтная система (гибриды MHEV/HEV/PHEV и электромобили BEV)  
Тяговая ВВ-батарея (деградация, балансировка ячеек), инвертор, тяговые электромоторы, редуктор привода, зарядный порт (GB/T, Type 2, CCS), система рекуперации, высоковольтная проводка, контур охлаждения ВВБ.  
	12. Кузов и остекление  
Оцинковка, очаги коррозии, скрытые полости, сварные швы, герметики, дренажные отверстия (люка/кузова), стойкость ЛКП, хром, стекла, замки и петли.  
	13. Салон и климатическая система  
Износ материалов отделки (руль, сиденья), эргономика, моторчик отопителя, компрессор кондиционера, радиатор печки, испаритель, скрипы, шумоизоляция.  
	14. Отзывные кампании  
Перечисли наиболее значимые мировые отзывные кампании (массовые, широко освещённые) для данного поколения, а также все официальные отзывные кампании, действовавшие на российском рынке. Для каждой кампании указывай год и суть проблемы. Если одна и та же кампания является одновременно глобальной и российской, укажи её один раз, не дублируя. Указывай только те кампании, действие которых распространяется на запрашиваемые годы выпуска. Если для данного поколения нет ни одной релевантной мировой или российской кампании, выведи ровно строку: Информация об отзывных кампаниях отсутствует.

6. СТЕПЕНЬ КРИТИЧНОСТИ (SEVERITY):
- «critical» — угроза безопасности движения или дорогостоящий отказ узла (капремонт ДВС, отказ тормозов, поломка АКПП/CVT, заклинивание руля).
- «medium» — техническая неисправность, требующая сервисного ремонта (подвеска, течи сальников/помпы, отказ генератора, ступичный подшипник).
- «low» — дефекты комфорта, скрипы салона, шумность, быстро стирающиеся кнопки, плохой свет фар.

7. ТОЧНАЯ ЦИТАТА-ДОКАЗАТЕЛЬСТВО (contextual_evidence_quote):
Обязательно включи чистую прямую цитату из отзыва, подтверждающую, что владелец лично столкнулся с этой проблемой.

ФОРМАТ ВЫВОДА РЕЗУЛЬТАТА:

        "expert_comment": "Слабый ресурс заводских резинометаллических шарниров на дорогах РФ."
      }
```

## 5. Этап 4. Валидация и загрузка результатов в БД

Скрипт `import_results.py` проверяет сохраненные JSON-файлы на корректность и загружает их в рабочую базу данных:

```python
# import_results.py
import json
import os
import glob
import sqlite3

RESULTS_DIR = "pipeline/output_batches"
DB_PATH = "cars_database.sqlite"

conn = sqlite3.connect(DB_PATH)
cursor = conn.cursor()

VALID_SYSTEMS = {
    "Двигатель", "Трансмиссия", "Подвеска", "Рулевое управление",
    "Тормозная система", "Электрика", "Кузов", "Салон"
}

files = glob.glob(os.path.join(RESULTS_DIR, "result_*.json"))
total_imported = 0

for filepath in files:
    with open(filepath, "r", encoding="utf-8") as f:
        data = json.load(f)

    for car_entry in data:
        car_id = car_entry.get("car_id")
        issues = car_entry.get("issues", [])

        for iss in issues:
            system = iss.get("system", "").strip()
            if system not in VALID_SYSTEMS:
                continue

            cursor.execute("""
                INSERT INTO car_issues (
                    car_id, system, issue_title, severity,
                    typical_mileage_km, occurrences, evidence_quote, expert_comment
                ) VALUES (?, ?, ?, ?, ?, ?, ?, ?)
            """, (
                car_id,
                system,
                iss.get("issue_title"),
                iss.get("severity", "medium"),
                iss.get("typical_mileage_km"),
                iss.get("occurrences_in_reviews", 1),
                iss.get("contextual_evidence_quote"),
                iss.get("expert_comment")
            ))
            total_imported += 1

conn.commit()
conn.close()
print(f"Успешно импортировано {total_imported} подтвержденных проблем!")
```
